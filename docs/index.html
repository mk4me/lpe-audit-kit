Run on this host (no install)

Stream the script through a shell — nothing is written to disk:

curl -fsSL https://raw.githubusercontent.com/mk4me/lpe-audit-kit/main/lpe-audit.sh | sh

With options:

curl -fsSL https://raw.githubusercontent.com/mk4me/lpe-audit-kit/main/lpe-audit.sh | sh -s -- --json
curl -fsSL https://raw.githubusercontent.com/mk4me/lpe-audit-kit/main/lpe-audit.sh | sh -s -- --quiet
Trust check: piping to sh is convenient but skips integrity verification. For a verified install, use curl ... /install.sh | sh below — it downloads, checks SHA256 against the published checksum, and only then runs.

Verified install (recommended for production)

curl -fsSL https://raw.githubusercontent.com/mk4me/lpe-audit-kit/main/install.sh | sh -s -- --run

Or save the verified script for later:

curl -fsSL https://raw.githubusercontent.com/mk4me/lpe-audit-kit/main/install.sh | sh
./lpe-audit.sh

Audit a remote host (no install on remote)

Stream the script through SSH — script runs from memory only:

curl -fsSL https://raw.githubusercontent.com/mk4me/lpe-audit-kit/main/lpe-audit.sh | ssh user@host 'bash -s'

With sudo on the remote (for full kernel module visibility):

curl -fsSL https://raw.githubusercontent.com/mk4me/lpe-audit-kit/main/lpe-audit.sh | ssh user@host 'sudo bash -s'

Or use the wrapper from the repo:

git clone https://github.com/mk4me/lpe-audit-kit.git
cd lpe-audit-kit
./remote-audit.sh --sudo --json admin@web-01

Audit your whole fleet

git clone https://github.com/mk4me/lpe-audit-kit.git
cd lpe-audit-kit
cp hosts.txt.example hosts.txt
# edit hosts.txt — one host per line: user@host
./fleet-audit.sh -i hosts.txt -c 16 --sudo

Output: per-host JSON, aggregated CSV matrix, and a summary report.

How it works

POSIX shell. Read-only. No external dependencies. Heuristic detection of module presence, blacklist files, userns posture, and AppArmor/SELinux state.

Tested on Ubuntu 18.04+, Debian 10+, RHEL/CentOS 7+, AlmaLinux 8+, Rocky Linux 8+, Fedora 36+, openSUSE Leap 15+, Alpine 3.15+, Amazon Linux 2/2023.

The script is heuristic by design — for definitive patch status, check your distro's CVE tracker (links printed at end of the report).
